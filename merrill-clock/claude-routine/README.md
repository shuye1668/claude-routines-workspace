# Claude Remote Routine 設定

## 這個排程做什麼

每個美股交易日，在美國開盤前：

1. 讀取 Google 文件「**美林時鐘 每日摘要**」（由 Apps Script 每日更新，含機器可讀 JSON）
2. 做深度關鍵分析：時鐘讀數可信度、轉折確認狀態、四類背離、風險結構、配置意涵與失效條件
3. 依警示等級（🔴／🟡／⚪）寄出 Email

## 需要的連接器

| 連接器 | 用途 |
|---|---|
| Google Drive | 讀取「美林時鐘 每日摘要」文件 |
| Gmail | 寄出警示信 |

## 前置條件

- Apps Script 端已執行過 `run_ExportDigest()`，Google 雲端硬碟裡存在「美林時鐘 每日摘要」文件
- Apps Script 的每日觸發器正常運作（否則排程會偵測到資料過期並在信中標註）

## 提示詞

排程的 prompt 本體見 [`ROUTINE_PROMPT.md`](ROUTINE_PROMPT.md)。
建立排程時把 `<<收件人>>` 與 `<<寄送模式>>` 換成實際值。

## 排程時間

cron 以 **UTC** 計算。建議在美股開盤前約 80 分鐘觸發，此時前一交易日的 FRED 資料已更新：

| 目的 | UTC cron | 台北時間 |
|---|---|---|
| 美股盤前（夏令時間） | `13 12 * * 1-5` | 每週一～五 20:13 |
| 美股盤前（冬令時間） | `13 13 * * 1-5` | 每週一～五 21:13 |

> 美國換日光節約時間時記得調整一次 cron，或直接固定用其中一個時段。

## 與 Apps Script 的信件如何分工

- **Apps Script**：只在偵測到轉折或跨越警示門檻時，寄一封快速的「事件通知」（純數據、無 AI）。
- **Claude routine**：每個交易日寄一封深度分析信，等級 ⚪ 時會刻意寫得很短。

兩者不重複：Apps Script 那封是「發生了什麼」，Claude 這封是「所以呢」。
若覺得太多，把指令碼屬性 `ALERT_EMAIL` 留空即可停掉 Apps Script 端的信。
