歸因紀律
因果鏈句式：「催化 X（絕對日期）→ 機制 → 股價反應」；禁倒推（「大漲反映市場樂觀」）。
「全球風險偏好」「市場情緒」「流動性」不可作為連結機制。
機制連續（承 asia-session-logic）：相鄰兩環之間必須寫出「上一環為什麼必然推向下一環」的財務或制度機制；任何一處需要讀者自行腦補＝跳環。優先檢查資金成本通道（誰在借錢、誰對利率敏感、槓桿在誰身上）。檢驗法：逐環問「刪掉這環，讀者還推得回來嗎？」
寫完自問：「這論點昨天也成立，為何今天才反應？」答不出 → 留白句型；股價漲不等於基本面已驗證。
量價：只有異常訊號（下跌爆量、天量、衝高爆量收低）才論述，順向量增不提。
催化劑量級檢查（每個主因下筆前必過）：主因催化劑的量級是否足以解釋指數的移動幅度？「解除疑慮／利空出清／籌碼消化／交割完成」型事件通常只移除拖累、難獨力造成全面急漲急跌（如大盤 ±2%、數十檔漲停）。量級不匹配 → 該催化降為次因，主脈絡改由總體（油價／CPI／Fed／地緣）或技術（去槓桿洗盤反彈／軋空／超跌反彈／獲利了結）承擔；寧可寫「今日為前一日急殺後的技術反彈」也不硬掛單一公司事件。
境外事件「日期＋性質」雙查證（引用任何非台灣事件作為台股主因前 100% 必做）：web_search 確認 (a) 事件真正日期（哪一個交易日）；(b) 事件性質——IPO 掛牌 ≠ 現金增資 ≠ 交割 ≠ 財報 ≠ 法說 ≠ 目標價調整，方向可能相反。BN Wrap 或記憶不可作為唯一來源。跨市場指數（如 SOX）標註日期前先確認是哪一個交易日的收盤（美股與台股日期常錯一日）。查不到確切日期／性質 → 不把該事件寫成主因。
具名催化句閘門：凡寫「催化來自 X／主因為 X／源頭是 X」的具名事件催化，該事件必須在本次搜尋中取得 publish date＝當日或前一交易日的來源；取不到 → 改寫為結構性表述（「與隔夜{類股}重挫同構、屬暴漲後獲利了結」）。敘事反轉檢查：今日催化與前一交易日敘事方向相反 → 高度懷疑撿到舊聞，必先確認是新報告（哪家機構、何日發布），確認不了就不寫。
總括詞閘門：「全面／全線／齊挫／皆墨／普漲」等總括詞，僅當結構數據支持（寬度壓倒性）才可用；指數與結構分化時必須寫結構性表述——分化本身是更高資訊量的寫法。

W1 句法模板庫
標題（body 首行 h2）：「{驅動短語}，台股{方向動詞}{結果短語}」或「台股{動詞}{座標／結果}，{因果子句}」。結構公式＝本質變化（因）——盤面後果（果），一個因果、一個重點。避用漲跌幅數字；禁時間軸流水帳、禁現象羅列、禁黑話入標題。標題陳述不得與記分板數據矛盾；必須與當日快報另立意。電梯測試：遮住全文只看標題，不看盤的高階主管能否五秒內複述「今天為什麼漲跌、接下來看什麼」？不能＝重寫。
導語（1 句、35–55 字、零數字）：「{驅動事件名詞化}，{台股反應動詞句}，{機制短語}」。
記分板句序：指數句（官方收盤、漲跌%、形狀短語、貢獻／拖累股具名）→ 櫃買一短句 → 寬度句 → 量能句（歷史座標）→ 法人句（「外資賣超 X 億元、連 N 日」——必含，除非資料確缺並於回報標註）→ 台幣句。記分板只放數據；判讀句一律放驅動段或籌碼定價段。
傳導鏈：「{事件}→{機制}→{資產反應}」逐環（正文以「因此／於是／這使得」寫成連續敘事，禁用箭頭符號）。
引述：「『……』，{人名} 於 {機構} 表示（轉引自 {媒體}）」；次級：「{機構}於盤後報告指出（轉引自 {媒體}）」。
個股一句話三要素（25–40 字）：「{標的}{動作＋幅度＋極值錨}，{單一因果}」；極值錨查無則省。
時間錨：「連 N 日」「自 X 以來最大」；集中度句：「台積電權重近四成」；「距 X 高（低）點」必標口徑。
While/Despite：「儘管{主敘事}，{逆勢者}逆勢{動作}，{邊界解釋}」。
定價句（v2 大幅擴充，見 §籌碼與定價段）：「台指期日盤基差{貼水／升水}擴至 X 點」「外資期貨淨空單增至 X 口、單日增 Y 口」「融資餘額單日減 X 億元、連 N 日」「夜盤台指期較日盤收盤{漲／跌} X 點」。當日大漲／大跌或反轉日，定價句為「應寫」；僅在確無資料時走 W2 降級。

W6 主脈絡 × 強弱勢印證（核心分析引擎，完整三步）

① 假設：美股前夜（BN Wrap）＋當日事件＋指數與類股表現 → 候選主敘事。 反轉日規則：今日與前一交易日方向相反且幅度大 → 必須把「前一日事件的超跌技術反彈／去槓桿洗盤後反彈／軋空／獲利了結」列為候選主脈絡，與任何單一公司催化並列評估，不得跳過。

② 印證：TWSE_Movers（強弱勢各 10 檔）＋ TWSE_Top30 ＋ 類股指數（TWSE_Market INDEX 列）＋ 貢獻／拖累結構——漲方集中受益族群？跌方集中受害族群？類股漲跌幅排序與主敘事同構？

③ 裁定（誠實）：吻合 → 結構對應句；部分 → 明寫哪部分本地主導；不吻合 → 修正主敘事或明寫背離。逆勢者能被主敘事邊界解釋 → 更可信；不能 → 調降語氣。

基本面或法人動態：營收、訂單、報價、評等、目標價、法人買賣超
族群或籌碼位階：族群共振 vs 個股獨立、量能倍數、位階、融資券
同鏈或總體連結：同鏈美股前夜表現，或當日利率／油價等總體因素對該股的作用機制

好的範例：「太陽誘電自今日起調漲 MLCC 報價、三星電機傳跟進，被動元件報價循環轉強（面向1＋2）；但國巨盤中一度摜至跌停、成交 397.7 億元居全市場第五、量能放大 1.6 倍，同族群禾伸堂卻收平（面向3）——報價利多未能推動股價，反映賣壓來自權值股本身的籌碼調節而非產業基本面。」 差的範例：「無查證到個股催化」「受惠 AI 題材」「族群共振」（無數字、無機制、無查證痕跡）。

其他要求：多面向互相矛盾時要點出來（利多但股價跌＝定價權不在公司手上，這是高價值觀察）；族群共振而非個股獨立事件時一定要明寫；漲跌停宣稱須有 Sheet 標記。
